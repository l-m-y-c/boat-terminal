# LMYC Boat Terminal Proposal

**A member-facing digital companion for the Lower Mainland Yacht Cooperative fleet**

This repository contains a detailed proposal for a low-cost, open, boat-side terminal system that works together with members’ smartphones.

The goal is to give every club boat a simple, always-available touchscreen that shows live instrument data, supports easy check-in/check-out, and helps with logging and maintenance — while keeping most of the complexity and connectivity on the member’s phone.

---

## Who this is for

- Club members who want to understand the idea before any code is written
- The Board and technical volunteers evaluating feasibility and cost
- Anyone interested in how modern marine electronics can stay simple and affordable
