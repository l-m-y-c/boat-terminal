# 01 – Executive Summary

## The Idea in One Paragraph

Every LMYC boat would have a small, always-on touchscreen terminal in the cabin.  
When a member arrives for a booked sail, they pair their phone with that terminal for the duration of the reservation.  
The terminal shows live instrument data (depth, wind, speed, battery, etc.), current booking status, and simple boat notes.  
The member’s phone continues to handle maps, weather, photos, and communication with the club’s existing web booking system.  
When the reservation ends, the pairing is released.

## Why This Approach?

LMYC already provides a solid online booking experience. This project simply extends that experience onto the boat in a lightweight, affordable way.

| Approach | Strengths |
|----------|-----------|
| Commercial MFD on every boat | Polished and integrated |
| Phone-only | Members already carry them |
| **Hybrid terminal + phone** | Low cost, open, always-available local display, builds directly on the existing booking system |

## Key Benefits for LMYC

- Live instrument data visible in the cabin at a glance
- A natural digital handshake between the web booking and the physical boat
- Easy capture of observations and engine hours while still on board
- Low ongoing cost — hardware is inexpensive and replaceable
- Fully compatible with the phones and web tools members already use
- Open and maintainable by club technical volunteers

## What It Is Not

- Not a replacement for the existing booking system
- Not a full commercial chartplotter or navigation system
- Not something that requires constant cellular coverage while sailing
- Not a system that stores sensitive personal data on the boat

## Rough Cost Reality

- Hardware per boat (terminal + cabling + enclosure): **CAD $80–150**
- Development effort: primarily volunteer / club technical members
- Ongoing cost: essentially zero for basic operation

## Recommendation

This is a low-risk way to make the excellent digital tools LMYC already has even more useful once members step aboard.  
A single-boat pilot would let the club evaluate the experience before any wider commitment.
