## 2. Start the recorder (leave it running all test)

```sh
python3 tools/console.py session --every 5 --out sessions/boat-2026-10-28
```

It prints one line every 5 s (frames/s, devices, PGN/source pairs, our address, lost frames, bus errors/REC, **bus-off**, tx refused, hint), and below it what changed: `NEW device`, `NEW PGN … from …`, `DUPLICATE …`, `OUR ADDRESS a -> b`, `BUS-OFF`, `bus errors +n`, `the terminal rebooted`. Everything goes to `sessions/boat-2026-10-28/` (`console.log`, `diag.jsonl`, `diag-latest.json`). A reboot or a pulled cable does not stop it; it waits (up to 120 s, `--wait`) and carries on. Ctrl-C prints the full summary (devices, value owners, PGNs per source).

In a second terminal, any time:

```sh
python3 tools/console.py diag                 # full summary now
python3 tools/console.py net --refresh        # device list with model / version / serial
python3 tools/console.py net --src 35         # one device
python3 tools/console.py diag --out sessions/boat-2026-10-28/diag-step-N.json
```

(Only one program can have the port open. Stop `session` for a moment, or run these between steps.)
